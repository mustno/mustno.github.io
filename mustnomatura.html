// 1. Algebra & Geometrie (AG)
THEMA FORMEL / BEZIEHUNG BMBWF-KLAUSURREGEL
Quadratische Gleichung x₁,₂ = (-b ± √(b² - 4ac)) / (2a)
Diskriminante: D = b² - 4ac		 D > 0: 2 Lösungen
D = 0: 1 Doppellösung
D < 0: keine reellen Lösungen
Lineare Gleichungssysteme I: a₁·x + b₁·y = c₁
II: a₂·x + b₂·y = c₂		 Mengen- und Wertgleichung strikt trennen! solve({Gl1, Gl2}, {x, y})
Rechtwinkeliges Dreieck sin(α) = Gegenk. / Hyp.
cos(α) = Ankathete / Hyp.
tan(α) = Gegenk. / Ankathete		 Achtung: Winkel immer im DEG-Modus berechnen!
Vektoren 2D Betrag: |v| = √(x² + y²)
Gegenvektor: -v = (-x | -y)
Skalarprodukt: a · b = a₁·b₁ + a₂·b₂ = 0 (orthogonal)		 Pfeilspitze und Beschriftung bei Zeichnungen exakt einzeichnen.
// 2. Funktionale Zusammenhänge (FA)
THEMA FORMEL / BEZIEHUNG BMBWF-KLAUSURREGEL
Lineare Funktion f(x) = k · x + d
k = (y₂ - y₁) / (x₂ - x₁) (Steigung)
d = y-Achsenabschnitt / Fixwert		 Einheit von k = [Einheit y] / [Einheit x]! Immer im Sachzusammenhang interpretieren.
Exponentialfunktion N(t) = N₀ · a^t = N₀ · e^(λ · t)
Wachstums-/Abnahmefaktor: a = 1 ± p
Halbwertszeit: a^(T_1/2) = 0.5 ⟹ T_1/2 = ln(0.5) / ln(a)		 100% Klausur-Garantie in ausnahmslos jedem Termin! a = e^λ ⟹ λ = ln(a).
Sinusschwingung f(t) = a · sin(b · t) + d
Amplitude: |a| = (y_max - y_min) / 2
Ruhelage: d = (y_max + y_min) / 2
Periode: T = 2π / b ⟹ b = 2π / T		 Standard-Winkelmodus ist hier ausnahmslos RAD (Bogenmaß)!
// 3. Analysis & Infinitesimalrechnung (AN)
THEMA FORMEL / BEZIEHUNG BMBWF-KLAUSURREGEL
Änderungsraten Mittlere Änderungsrate: (f(b) - f(a)) / (b - a) (Sekante)
Momentane Änderungsrate: f'(t) = lim[h➔0] (f(t+h) - f(t))/h (Tangente)		 Signalwort "momentan" / "zu diesem Zeitpunkt" ⟹ 1. Ableitung! Einheit stets y/x.
Kurvendiskussion (NEW-Regel) Hoch-/Tiefpunkt: f'(x) = 0 und f''(x) ≠ 0
Wendepunkt: f''(x) = 0 und f'''(x) ≠ 0
Wendepunkt = stärkste Zu- bzw. Abnahme!		 NEW-Regel: Nullstelle in f''(x) = Extremum in f'(x) = Wendepunkt in f(x).
Bestimmtes Integral ∫[a bis b] f(t) dt = F(b) - F(a)
Bestandsrekonstruktion: B(t) = B(0) + ∫[0 bis t] f(τ) dτ		 Fläche unter der Änderungsrate ergibt den Gesamtzugang bzw. die Bestandsänderung.
// 4. Wahrscheinlichkeit & Statistik (WS)
THEMA FORMEL / BEZIEHUNG BMBWF-KLAUSURREGEL
Binomialverteilung P(X = k) = (n über k) · p^k · (1 - p)^(n - k)
Mindestens 1 Treffer: P(X ≥ 1) = 1 - P(X = 0) = 1 - (1 - p)^n
Erwartungswert: μ = n · p		 binomPdf(n, p, k) für genau k.
binomCdf(n, p, k1, k2) für Bereiche k₁ bis k₂.
Normalverteilung z = (x - μ) / σ (Standardisierung)
Symmetrisches 95%-Intervall: [μ - 1.96·σ, μ + 1.96·σ]
68.3% im Bereich [μ - σ, μ + σ]		 normCdf(untere, obere, μ, σ) für Fläche.
invNorm(Fläche_links, μ, σ) für Quantilgrenze.
Beschreibende Statistik & Boxplot Median z = Q₂ (50% der Daten)
Interquartilsabstand: IQR = Q₃ - Q₁
Ausreißer: Werte < Q₁ - 1.5·IQR oder > Q₃ + 1.5·IQR		 Median ist robust gegen Ausreißer! Der Mittelwert verschiebt sich bei Extremwerten stark.
